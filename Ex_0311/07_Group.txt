-- 그룹함수: 여러 행 또는 테이블 전체에 대하여 하나의 결과를 가져오는 함수
1) AVG(): 평균값
2) COUNT(): 조회된 행(row)의 갯수를 반환
3) MAX(): 최댓값
4) MIN(): 최솟값
5) SUM(): 총 합을 구하는 함수

-- GROUP BY 절
1) 특정 컬럼이나 값을 기준으로 해당 레코드를 묶어서 자료를 관리하기위해 사용
2) 그룹함수와 함께 사용하여 효과를 극대화 할 수 있다.
SELECT job_id, count(*)
FROM EMPLOYEES
GROUP BY job_id;

-- 매니저 별로 담당직원수
SELECT manager_id, count(*)
FROM EMPLOYEES
GROUP BY manager_id

-- 각 부서별 급여의 평균과 총 합을 구하자
부서별로 그룹화 하여 부서번호, 인원수, 급여의 평균과 총 합순으로 출력
SELECT department_id, count(*), trunc(AVG(salary)), SUM(salary)
FROM EMPLOYEES
GROUP BY department_id;

-- 직종별 급여의 합계
SELECT job_id, SUM(salary)
FROM EMPLOYEES
GROUP BY job_id

-- 직종별 급여의 평균을 소수점 한자리 까지 반올림해서 표기
SELECT job_id, ROUND(AVG(salary), 1)
FROM EMPLOYEES
GROUP BY job_id;

-- 부서별, 직종별 급여의 합 부서 번호가 낮은 순으로 정렬, 부서번호, 직종, 급여의 합
SELECT department_id, job_id, SUM(salary) as sum
FROM EMPLOYEES
GROUP BY department_id, job_id
ORDER BY department_id, job_id, sum

-- 각 부서별로 가장 높은 급여, 가장 낮은 급여를 출력
SELECT department_id, MAX(salary), MIN(salary)
FROM EMPLOYEES
GROUP BY department_id

-- 부서별 급여의 합, 급여의 합 내림차순으로 정렬
SELECT department_id, SUM(salary) sum
FROM EMPLOYEES
GROUP BY department_id
ORDER BY sum DESC;

-- 부서별 인원수, 급여의 합, 평균을 출력 인원이 많은 순으로 정렬
SELECT department_id, COUNT(*) count, SUM(salary) sum, ROUND(AVG(salary), 2) avg
FROM EMPLOYEES
GROUP BY department_id
ORDER BY count DESC;

-- 부서별, 직종별, 보너스를 받는 사원수를 출력
SELECT department_id, job_id, COUNT(commission_pct) pct
FROM EMPLOYEES
GROUP BY department_id, job_id
ORDER BY department_id

-- 부서별, 직종별, 보너스를 받지않는 사원수를 출력
SELECT department_id, job_id, COUNT(*) - COUNT(commission_pct) 
FROM EMPLOYEES
GROUP BY department_id, job_id
 
-- 부서별, 직종별 급여의 합, 사원 수, 평균 급여를 부서 번호가 낮은 순, 급여의 합이 큰 순으로 정렬, 평균급여는 소수점 한자리까지 반올림
SELECT department_id, job_id, COUNT(*), SUM(salary), ROUND(AVG(salary), 1)
FROM EMPLOYEES
GROUP BY department_id, job_id
ORDER BY department_id, SUM(salary) DESC;

-- 부서별 직종별, 급여의 합, 평균 급여를 출력 
부서 번호 낮은 순, 급여합계 낮은 순 평균 급여는 소수점을 절삭
SELECT department_id, job_id, SUM(salary), floor( AVG(salary))
FROM EMPLOYEES
GROUP BY department_id, job_id
ORDER BY department_id, sum(salary);


-- 그룹 함수를 사용할 때 알아야 할 조건
-- having 절
GROUP BY 다음에 나오는 조건문으로 GROUP BY 결과에 조건을 줘서 제한을 할 때 사용
WHERE에서는 그룹함수를 사용할 수 없다.

-- 각 부서별 인원수를 출력, 10명 이상인 부서만 조회
SELECT department_id, COUNT(*)
FROM EMPLOYEES
GROUP BY department_id 
HAVING COUNT(*) >= 10;

-- 직종별 급여의 최댓값 출력
단, 최대 급여가 5000을 초과하는 경우만 출력
SELECT job_id, MAX(salary)
FROM EMPLOYEES
GROUP BY job_id HAVING MAX(salary) > 5000

-- 부서별 급여의 합, 소수점 두 자리에서 반올림한 평균, 인원수를 출력
급여의 합이 30000이상인 경우만 출력
SELECT department_id, SUM(salary), ROUND(AVG(salary), 2), COUNT(*)
FROM EMPLOYEES
GROUP BY department_id
HAVING sum(salary) >= 30000

-- 각 부서별 인원수가 20명 이상인 부서의 정보를 부서번호, 급여의 합, 급여의 평균(반올림), 인원수 순으로 출력
SELECT department_id, SUM(salary), ROUND(AVG(salary)), COUNT(*)
FROM EMPLOYEES
GROUP BY department_id
HAVING COUNT(*) >= 20;

-- 각 부서별 부서번호, 최대급여, 최소급여, 인원수를 출력
단, 급여의 최댓값이 8000이상인 경우, 부서번호가 존재하는 경우의 결과만 출력 부서번호가 낮은 순으로 정렬
SELECT department_id, MAX(salary), MIN(salary), COUNT(*)
FROM EMPLOYEES
WHERE department_id IS NOT NULL
GROUP BY department_id
HAVING MAX(salary) >= 8000 
ORDER BY department_Id;

-- 각 부서별 평균 급여를 조회
단, 평균 급여가 10000미만인 그룹만 조회
부서 번호가 50 이하인 결과만 출력
SELECT department_id, AVG(salary)
FROM EMPLOYEES
WHERE department_id <= 50
GROUP BY department_id
HAVING AVG(salary) < 10000
ORDER BY department_id 

-- 직종이 IT_PROG인 사원들의 급여의 평균, 급여의 합을 출력
SELECT job_id, AVG(salary), SUM(salary)
FROM EMPLOYEES
WHERE job_id = 'IT_PROG'
GROUP BY job_id

-- 부서 번호, 직종, 인원수를 출력
직종이 man으로 끝나는 직종만 조회
SELECT department_id, job_id, COUNT(*)
FROM EMPLOYEES
WHERE job_id LIKE '%MAN'
GROUP BY department_id, job_id
